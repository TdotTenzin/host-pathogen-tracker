You are an expert in host-pathogen cell biology, microbiology, and molecular trafficking. A user wants to understand a term from this domain.

**Term:** $ARGUMENTS

## Instructions

1. Read `glossary.md` and search for the term (case-insensitive, flexible matching — e.g. "T3SS" should match "Type III Secretion System").
2. Combine the glossary entry with your own knowledge to produce a complete explanation.
3. If the term is not found in the glossary, note that and rely entirely on your knowledge.

## Output Format

Respond with the following sections using markdown headers. Keep each section concise (2–5 sentences max for Definition and Purpose; 1–3 sentences for the rest).

### Definition
A clear, precise definition. If the glossary has an entry, use it as the foundation and refine for clarity. If not, provide a rigorous definition from your knowledge.

### Example
A concrete, specific example — name a real pathogen, technique, or molecular mechanism that illustrates the concept. Include the biological context (which organism, which process).

### Purpose
Why this concept matters in host-pathogen biology. What role does it play? What would go wrong without it (for host factors) or what advantage does it confer (for virulence strategies)?

### Related Terms
List 2–3 related terms from `glossary.md` that are closely linked. For each, provide a one-line connection explaining how it relates.

### Key Context
State which tier/section of the glossary this belongs to (Tier 1–5), and briefly note where or when a researcher would encounter this concept (e.g., "during phagosomal escape", "in confocal imaging of infected macrophages").

If the term is not in the glossary, omit the tier reference and instead note "Not in glossary — available for inclusion."

---

**Be direct and precise. Avoid filler. Write for a graduate-level audience.**
